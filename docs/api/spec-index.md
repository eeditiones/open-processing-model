# spec_index

Graph of ODD specification elements: elements, classes, macros, datatypes,
processing models, and the direct facts about them — memberships and
content-model references — indexed for lookup.

::: opm.spec_index

What the index means on a documentation page — contained-by, may-contain,
members, used-by, the attribute tree — is derived in
[`opm.odd_expand`](document-site.md#expanding-the-tree).
