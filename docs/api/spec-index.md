# spec_index

Graph of ODD specification elements: elements, classes, macros, datatypes,
processing models, and the direct facts about them — memberships and
content-model references — indexed for lookup.

::: opm.spec_index

## `tp:` primitives

The index's lookups as XPath functions, for the documentation ODD and a
project's own `tp:` functions to compose from.

::: opm.runtime.spec_primitives

## `tp:` documentation functions

What a reference page says about a spec — contained-by, may-contain, members,
used-by, the attribute tree, the catalogs, the numbering — composed from the
primitives. A documentation project replaces any of them by defining a
function of the same name in its own extension module.

::: opm.runtime.spec_xpath_functions
